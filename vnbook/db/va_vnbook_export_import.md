# VNBook 数据库导入导出功能文档

## 1. 概述

本文档描述了 VNBook 单词本应用的用户数据库导入导出功能，用于管理员数据备份与迁移。

**核心功能**：

- 导出：将用户数据导出为 `.vnb` 压缩文件
- 导入：在数据库初始状态下恢复数据
- 清空：重置数据库为初始状态（仅保留 admin）

**相关文件**：

- 后端：`public/api/system.php`
- 前端API：`src/api/system.ts`
- 前端UI：`src/views/SystemManageView.vue`
- 业务逻辑：`src/composables/useUserOperations.ts`

## 3. 数据范围

### 3.1 导出表结构

导入导出涵盖以下8个表，形成完整的数据依赖树：

```
vnb_users (用户表)
├── vnu_books (单词本表)
├── vnu_words (单词表)
│   └── vnu_explanations (释义表)
│       └── vnu_sentences (例句表)
├── vnu_mapbw (单词本-单词映射表)
└── vnu_review (复习记录表)
vnb_pos (词性标准配置表)
```

**导出规则**：

- 仅导出非 `admin` 用户数据
- 包含完整的用户数据关联关系

## 4. 导出功能

### 4.1 核心流程

1. **状态检查**：验证数据库是否包含用户数据
2. **用户确认**：显示导出确认对话框
3. **数据处理**：
   - 后端查询所有相关表数据
   - 生成UTF-8 JSON格式
   - 使用gzip压缩（压缩率约84%）
   - 生成SHA256校验和
4. **文件下载**：
   - 前端使用Blob方式下载
   - 自动获取服务器返回的文件名
   - 显示导出成功提示

### 4.2 技术要点

- **压缩格式**：gzip（最高压缩率）
- **文件命名**：`vnbook_export_YYYYMMDD_HHMMSS.vnb`
- **校验机制**：SHA256校验和
- **响应头**：包含文件名和校验和信息

## 5. 导入功能

### 5.1 两阶段验证

**阶段一：数据库状态检查**

- 检查数据库是否为空（仅保留admin）
- 非空状态禁止导入

**阶段二：文件验证与导入**

- 验证文件格式（.vnb或.json）
- 检查文件大小（≤50MB）
- 验证文件内容格式

### 5.2 导入流程

1. **文件处理**：读取并解压文件，解析JSON
2. **安全检查**：二次验证数据库状态
3. **数据导入**：
   - 禁用外键检查（保持原始ID）
   - 按依赖顺序分批导入（每批1000条）
   - 跳过 `vnu_books.nums` 字段（由触发器维护）
   - 启用外键检查并提交事务
4. **结果反馈**：显示详细导入统计

### 5.3 特殊处理

- **vnu_books.nums**：跳过该字段，由触发器自动计算
- **批量导入**：每批1000条，避免超时和内存溢出
- **事务管理**：支持错误回滚，确保数据一致性

## 8. 用户操作指南

### 8.1 导出数据

**前提**：以admin身份登录，数据库包含用户数据

**步骤**：

1. 进入"系统管理"页面
2. 点击"导出数据"
3. 确认操作
4. 浏览器自动下载 `.vnb` 文件

### 8.2 导入数据

**前提**：以admin身份登录，数据库为空（仅保留admin）

**步骤**：

1. 进入"系统管理"页面
2. 点击"导入数据"
3. 系统检查数据库状态
4. 选择 `.vnb` 文件
5. 等待导入完成
6. 查看导入统计信息

### 8.3 清空数据库

**警告**：此操作不可逆！

**步骤**：

1. 进入"系统管理"页面
2. 点击"清空重置"
3. 确认操作
4. 所有用户数据将被删除（admin保留）

## 9. 错误处理

### 9.1 常见错误

- **权限不足**：非admin用户操作
- **数据库非空**：导入前未清空数据库
- **文件错误**：文件格式不正确或损坏
- **大小超限**：文件超过50MB限制
- **超时**：导入大文件时PHP执行超时

### 9.2 解决建议

- 确保使用admin账户操作
- 导入前先执行"清空重置"
- 验证导出文件完整性
- 大文件分批处理
- 调整PHP和服务器配置
